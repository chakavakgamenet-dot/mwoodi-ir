# Backend

Laravel API application target.

Recommended packages/features:
- Laravel Sanctum
- Form Requests for validation
- Policies/Gates for RBAC
- Jobs + Redis for async work
- Notifications for order status
- Laravel scheduler for cleanup/report jobs
- PostgreSQL transactions with row locks for inventory

Suggested modules:
Auth, Catalog, Cart, Checkout, Orders, Payments, Admin, Settings, Audit.
